### README (Supplementary Fig S4)

Executing "FigS4.py" generates Fig. S4 (A to C): emergent newborn volume, surface-to-volume ratio and efficiency against growth rate, and single-cell trajectories, when the flux balance is coupled to cell dynamics instead of imposing the empirical growth laws. Volume grows exponentially at the growth rate given by the flux balance at the cell's current envelope fraction, division is triggered by a threshold amount of division protein accumulated in proportion to volume (an adder), and surface area is synthesized at a rate beta V with beta = nu kappa V_b^(-1/3) set at birth so that the aspect ratio eta is preserved (nu(eta) = eta pi (eta pi/4 - pi/12)^(-2/3)). The threshold X0/k_p is calibrated so that the newborn volume at kappa_crit equals the empirical value for eta = 4. The diffusion penalty is off. The model functions are imported from ../Figures_2_and_3/methods22.py. Run from this folder; output FigS4.pdf and FigS4_data.json go to "images". Takes about a minute.
