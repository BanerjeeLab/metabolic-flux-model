### README (Figure 2 and Figure 3)

Executing the Python script "Fig2_Fig3_eGAMvary.py" generates all the subfigures needed for both Figure 2 and Figure 3, using "methods22.py" to load the relevant functions. 

Figure name mappings (.svg files in "images" subfolder) as generated by the script:
- Fig. 2A: growthLawsNoCrowd_eGAM8.00Proteome.svg
- Fig. 2B: growthLawsNoCrowd_eGAM8.00GrowthRate.svg
- Fig. 2C: growthLawsNoCrowd_eGAM8.00OutRate.svg
- Fig. 3A: 3A.svg
- Fig. 3B: growthLawsNoCrowd_eGAM8.00Energy.svg
- Fig. 3C: 3C.svg

The code uses an earlier notation than the manuscript (e.g. the glycolytic sector was renamed $F$ -> $G$).
Code variables map to manuscript symbols as follows
(code -> manuscript):
- phiF -> $\phi_G$
- JF -> $J_G$
- eF -> $e_G$
- epsilonF -> $\epsilon_G$
- phiOMaxFrac -> $\gamma$
- beta -> $\beta'$
- betaT -> $beta/T$

Additional comments:
- The crowding (diffusion) function in methods22.py is switched off for Figures 2 and 3: Fig2_Fig3_eGAMvary.py calls it with switch=False, so it returns 1 and has no effect. beta must still be passed as an argument but is unused here. Crowding is active only in the Figure 5 and 6 code.
- The code internally represents concentrations in units of molecule count per cubic micron; these are converted to micromolar (uM) for plotting.
