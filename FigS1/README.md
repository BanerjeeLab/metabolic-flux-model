### README (Supplementary Fig S1)

Executing the Python script "KC_vary.py" generates the subfigures needed for Supplementary Figure S1, using "methods22.py" to load the relevant functions. 

Figure name mappings (.svg files in "images" subfolder) as generated by the script:
- Fig. S1A: EfficiencyGrowth_KCvary.svg
- Fig. S1B: EfficiencySurfaceVolume_KCvary.svg
- Fig. S1C: GrowthRate_KCvary.svg

The code uses an earlier notation than the manuscript (e.g. the glycolytic sector was renamed $F$ -> $G$).
Code variables map to manuscript symbols as follows
(code -> manuscript):
- phiF -> $\phi_G$
- JF -> $J_G$
- eF -> $e_G$
- epsilonF -> $\epsilon_G$
- phiOMaxFrac -> $\gamma$
- beta -> $\beta'$
- betaT -> $\beta/T$

Additional comments:
- The crowding (diffusion) function in methods22.py is switched off for Figures S1, so it returns 1 and has no effect. beta must still be passed as an argument but is unused here. Crowding is active only in the Figure 5 and 6 code.
- The code internally represents concentrations in units of molecule count per cubic micron; these are converted to micromolar (uM) for plotting.
