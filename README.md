# metabolic-flux-model
Computational metabolic flux model for a growing bacterium, coupling cell shape and proteome allocation, as detailed in: "Bacterial biosynthetic efficiency is constrained by cell geometry and intracellular diffusion", A. Cylke, I. Badvaram & S. Banerjee, doi: https://doi.org/10.64898/2026.07.25.740728

This repository is organized by figure. Each figure folder contains its own README with output filenames, run instructions, figure-specific notes, and the code-to-manuscript notation map. Dependencies: Python 3.11 with numpy, scipy, and matplotlib.
