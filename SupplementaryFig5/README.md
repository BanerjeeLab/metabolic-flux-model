### README (Supplementary Fig S5)

Executing "FigS5.py" generates Fig. S5 (A to D): cell volume, surface-to-volume ratio, growth rate and acetate excretion along single-cell trajectories of the emergent-geometry model of Fig. S4 (aspect ratio 4, diffusion penalty off) through a glucose upshift from 5 to 40 uM and the reverse downshift. The model is imported from ../SupplementaryFig4/FigS4.py. Run from this folder; output FigS5.pdf goes to "images". Takes about a minute.
