### README (Figure 4)

Executing the script "simGrowthLawsPerturbationVolume.py" generates subfigures 4A and 4B.
Executing the script "simGrowthLawsPerturbation.py" generates subfigures 4C and 4D
Both these scripts use "methods22.py" to load the relevant functions. 

Figure name mappings (.svg files in "images" subfolder) as generated by the scripts:
- 4A, 4B, 4C, 4D: labeled as is

The code uses an earlier notation than the manuscript (e.g. the glycolytic sector was renamed $F$ -> $G$).
Code variables map to manuscript symbols as follows
(code -> manuscript):
- phiF -> $\phi_G$
- JF -> $J_G$
- eF -> $e_G$
- epsilonF -> $\epsilon_G$
- phiOMaxFrac -> $\gamma$
- beta -> $\beta'$
- betaT -> $\beta/T$

Additional comments:
- The crowding (diffusion) function in methods22.py is switched off for Figure 4. "simGrowthLawsPerturbation.py" and "simGrowthLawsPerturbationVolume.py" both call it with switch=False, so it returns 1 and has no effect. beta must still be passed as an argument but is unused here. Crowding is active only in the Figure 5 and 6 code.
- The code internally represents concentrations in units of molecule count per cubic micron; these are converted to micromolar (uM) for plotting.
